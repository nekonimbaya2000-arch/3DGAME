# Постоялец

Хоррор от первого лица в браузере. Вы исследуете паранормальные явления и приезжаете в заброшенную гостиницу «Кедровая» в посёлке Ялуга. Письмо с приглашением отправили в феврале 1988 года, а пришло оно на прошлой неделе.

Оружия нет. Выжить помогают внимательность, приборы и знание правил здания.

## Как запустить

Откройте `index.html` в Chrome, Edge или Firefox. Нужен интернет: 3D-движок (three.js r128) и шрифты загружаются с CDN. Лучше играть в наушниках.

Если включить GitHub Pages (Settings → Pages → Deploy from a branch → `main`, папка `/`), игра будет доступна по ссылке вида `https://<имя>.github.io/3DGAME/`.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | передвижение |
| Мышь | осмотреться (клик захватывает курсор) |
| Shift | бег — его слышно |
| F | фонарь |
| E | осмотреть / взять |
| Q | постучать в дверь |
| C | поставить зажжённую свечу (сцена 2) |
| 1 / 2 | ЭМП-детектор / термометр |

## Сцены

1. **Вестибюль.** Стойка регистрации, книга гостей и коммутатор, который давно отключён от линии, но звонит. От вашего решения зависит, что будет дальше.
2. **Второй этаж.** Номера с первого по четырнадцатый. Лампы в коридоре гаснут по очереди: это идёт Мотылёк, который тянется к свету.

## Технически

Один HTML-файл без сборки. Геометрия и текстуры генерируются в коде, весь звук синтезируется через Web Audio API, аудиофайлов нет.
